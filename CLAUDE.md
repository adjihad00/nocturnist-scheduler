# CLAUDE.md — Project Rules

## Startup
- **Always read `PROJECT_CONTEXT.md` at the start of every new conversation** before doing any work. This file contains critical project context, staffing facts, hospital assignments, decisions made, and current phase status.

## After Changes
- **Update `PROJECT_CONTEXT.md` after making meaningful changes** to the project. This includes:
  - New features or screens added
  - Changes to survey fields, labels, or data points
  - Architectural decisions or new conventions
  - Phase status updates
  - New files added to the repo structure
  - Any decision that would affect future work
- Keep updates concise and in the existing format/style of the document.
- Do NOT update for trivial cosmetic tweaks (e.g., color changes, minor spacing fixes) unless they change the functional description of a feature.
